# Student Progress Tracking（学生学情跟踪）

## 项目概述
一个学生学情跟踪系统，用于记录、分析和可视化学生的学习进度、成绩趋势与能力发展。

## 项目结构

```
student-progress-tracking/
├── docs/                    # 项目文档
│   ├── PRD.md              # 产品需求文档
│   └── API.md              # API 设计文档
├── backend/                 # 后端服务（技术栈待定）
│   ├── src/                # 源代码
│   └── tests/              # 测试用例
├── frontend/                # 前端应用（技术栈待定）
│   ├── src/                # 源代码
│   └── public/             # 静态资源
├── database/                # 数据库脚本
│   └── migrations/         # 迁移文件
├── data/                    # 数据文件
│   └── sample/             # 样例数据
└── scripts/                 # 工具脚本
```
