# 开发路线图与里程碑（Development Roadmap）

## 项目阶段概览

```
Phase 1 (Week 1-2)    基础设施 + 核心数据模型
Phase 2 (Week 3-4)    用户/班级/知识图谱管理后台
Phase 3 (Week 5-6)    试卷上传 + OCR + 题目解析
Phase 4 (Week 7-8)    AI 判卷引擎 + 知识模型更新
Phase 5 (Week 9-10)   诊断报告 + 出题引擎
Phase 6 (Week 11-12)  练习闭环 + 错题本 + 班级热力图
Phase 7 (Week 13+)    优化 + 监控 + 生产部署
```

---

## Phase 1：基础设施与核心数据模型（Week 1-2）

**目标**：搭建可运行的开发环境，完成数据库和基础框架

### Week 1：工程脚手架
- [ ] 初始化后端工程（FastAPI + SQLModel + Alembic）
- [ ] 初始化前端工程（React 19 + Vite + TypeScript + Ant Design）
- [ ] 编写 Docker Compose 开发环境（PostgreSQL + Redis + Qdrant + MinIO）
- [ ] 搭建项目 CI（GitHub Actions：lint + type-check）
- [ ] 配置 pre-commit（black, ruff, mypy, eslint）

### Week 2：数据层与认证
- [ ] 实现所有 SQLModel 数据模型（14 张核心表）
- [ ] 编写 Alembic 初始迁移脚本
- [ ] 实现 JWT 认证中间件（登录/刷新/权限校验）
- [ ] RBAC 权限系统（admin/teacher/student/parent 四角色）
- [ ] 基础 API：用户 CRUD、登录、获取当前用户
- [ ] 前端：登录页、布局框架、路由守卫

**交付物**：
- `docker-compose up` 一键启动完整开发环境
- 可登录的后台系统框架
- 14 张数据库表 + 初始迁移

---

## Phase 2：管理后台（Week 3-4）

**目标**：教师和管理员可以维护基础数据

### Week 3：组织架构
- [ ] 学科管理（增删改查）
- [ ] 知识点树维护（拖拽排序、父子关系、编码自动生成）
- [ ] 知识点关系编辑（前置/包含/相关/延伸）
- [ ] 班级管理（创建班级、分配教师、学生批量导入 Excel）
- [ ] 学生档案页（基本信息、所在班级、考试历史）

### Week 4：题目库
- [ ] 题目模板 CRUD（支持 LaTeX 编辑器）
- [ ] 题目分类筛选（知识点、题型、难度）
- [ ] 批量导入题目（JSON/Excel 模板）
- [ ] 题目向量入库（调用 Embedding API → Qdrant）
- [ ] 相似题检索测试页

**交付物**：
- 教师可维护知识点树和题目库
- 班级学生批量导入
- 向量检索可用

---

## Phase 3：试卷处理流程（Week 5-6）

**目标**：实现从上传试卷到拆题的完整流程

### Week 5：上传与存储
- [ ] 试卷上传组件（拖拽多文件、PDF/图片、进度条）
- [ ] MinIO 对象存储集成（分桶：原始试卷 / OCR结果 / 生成文件）
- [ ] 考试管理页（创建考试、关联班级、设置总分）
- [ ] 试卷分页预览（PDF.js / 图片画廊）

### Week 6：OCR 与版面分析
- [ ] OCR 任务队列（Celery + Redis）
- [ ] Mathpix API 客户端（公式识别）
- [ ] Qwen-VL / GPT-4V 多模态 OCR 客户端
- [ ] OCR 结果结构化解析（题号、题干、选项、作答区坐标）
- [ ] 人工校对界面（对照原图修正 OCR 结果）
- [ ] 题目与试卷关联（exam_questions 实例化）

**交付物**：
- 上传试卷 → OCR 识别 → 人工校对 → 生成 exam_questions 的完整流程
- OCR 任务监控面板

---

## Phase 4：AI 判卷与知识建模（Week 7-8）

**目标**：实现自动判卷、错因分析、学生知识模型更新

### Week 7：判卷引擎
- [ ] DeepSeek API 客户端封装（支持流式/非流式、重试、降级）
- [ ] 判卷 Prompt 工程（Few-shot + JSON Schema 强制输出）
- [ ] 判卷结果结构化：正误、得分、错因类型、知识点映射、置信度
- [ ] 批量判卷异步任务（Celery，支持进度查询）
- [ ] 判卷结果审核页（教师可一键修正、打回重判）
- [ ] AI 调用日志记录（成本追踪、异常监控）

### Week 8：知识模型
- [ ] BKT 简化算法实现（P(掌握) 更新）
- [ ] ELO 变体算法（根据题目难度调整掌握度）
- [ ] 时间衰减计算（PostgreSQL 函数）
- [ ] 学生知识状态查询 API（掌握度、趋势、薄弱点）
- [ ] 知识雷达图数据接口
- [ ] 前端：学生学情画像页（雷达图、掌握度列表）

**交付物**：
- 试卷自动判卷准确率 > 90%（数学客观题/简单主观题）
- 学生知识模型可实时更新
- 学情画像可视化

---

## Phase 5：诊断报告与出题引擎（Week 9-10）

**目标**：基于知识模型生成诊断报告和针对性练习

### Week 9：诊断报告
- [ ] 报告生成模板（单次考试 / 周度 / 月度）
- [ ] 薄弱知识点 TOP5 算法（结合掌握度 + 错误频次 + 重要性权重）
- [ ] 错误类型分布统计（饼图/柱状图数据接口）
- [ ] 历次趋势对比（折线图数据）
- [ ] AI 自然语言评语生成（Prompt：基于结构化数据总结，避免幻觉）
- [ ] 报告查看页（PDF 导出、分享链接）

### Week 10：出题引擎
- [ ] 出题 Prompt 工程（知识点 + 难度 + 题型 + 错误类型 → 题目）
- [ ] 答案自验证机制（独立 LLM 求解对比，不一致则重试）
- [ ] 题目生成异步任务（避免前端超时）
- [ ] RAG 增强：从 Qdrant 检索相似经典题作为 Few-shot 示例
- [ ] 练习卷组装（选题策略：基础巩固 40% + 变式提升 40% + 综合应用 20%）
- [ ] 前端：练习卷预览、调整题目、一键发布

**交付物**：
- 诊断报告自动生成（含可视化图表）
- AI 出题可用（带答案验证）
- 练习卷可发布给学生

---

## Phase 6：练习闭环与增强功能（Week 11-12）

**目标**：完成训练闭环，增强教师体验

### Week 11：练习闭环
- [ ] 学生在线答题界面（支持选择题、填空题、简答题）
- [ ] 简答题拍照上传（手写答案 → OCR → 判卷）
- [ ] 练习自动判卷（客观题即时反馈，主观题异步）
- [ ] 练习结果更新知识模型
- [ ] 错题自动入库（error_book_items）

### Week 12：错题本与班级分析
- [ ] 错题本页（按知识点分章、筛选、排序）
- [ ] 相似错题推荐（向量检索）
- [ ] 错题本 PDF 导出（排版优化，含原题+正解+解析）
- [ ] 班级薄弱知识点热力图（ECharts 热力图）
- [ ] 教师审核工作台（批量修正判卷、标记题目质量问题）
- [ ] 自适应练习推送（间隔重复算法决定复习时机）

**交付物**：
- 学生可在线完成针对性练习
- 错题本自动维护
- 班级学情热力图

---

## Phase 7：优化与生产部署（Week 13+）

### 性能优化
- [ ] PostgreSQL 查询优化（慢查询分析、索引调优）
- [ ] Redis 缓存热点数据（用户信息、知识点树）
- [ ] Celery Worker 水平扩展配置
- [ ] 前端懒加载、代码分割、PWA 离线缓存

### 监控与运维
- [ ] Prometheus + Grafana 监控大盘（API QPS、延迟、错误率）
- [ ] AI 成本监控（按模型/按任务类型统计月度费用）
- [ ] 日志聚合（结构化 JSON 日志，按 trace_id 串联请求链）
- [ ] 健康检查端点（/health, /ready）

### 安全加固
- [ ] 数据脱敏（学生姓名替换代号，试卷图片加水印）
- [ ] API 限流（Rate Limiting，按用户级别）
- [ ] 敏感操作审计日志（删除、修改判卷结果）

### 部署
- [ ] 生产环境 Docker Compose / K3s 配置
- [ ] Nginx 反向代理 + SSL 证书
- [ ] 数据库备份策略（每日自动备份）
- [ ] 蓝绿部署 / 滚动更新方案

**交付物**：
- 生产环境可部署
- 监控报警完善
- 系统稳定运行
